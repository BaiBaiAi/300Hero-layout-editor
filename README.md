# 300英雄大厅布局编辑器

一个可移植的本地 Web 编辑器，用于分析、预览、批量调整和安全写入 300英雄大厅及竞技场 Lua 布局。

## 下载与运行

从 [GitHub Releases](https://github.com/BaiBaiAi/300Hero-layout-editor/releases) 下载 `300Hero-Layout-Editor.exe`，放入一个独立文件夹后双击运行。首次启动会要求选择包含 `Data*.jmp` 的 300英雄游戏目录，选择结果保存在 EXE 同目录的 `config/settings.json`。

使用源码运行：

```powershell
python -m pip install -r requirements.txt
python app.py
```

也可以直接双击 `start_editor.bat`。

## 版本与恢复

- 每次点击“应用到游戏”前，程序都会从当前 JMP 抽取这次即将修改的 Lua，保存到 `version_history/<游戏目录标识>/<时间>/`，作为本次写入前的“上一个版本”。
- `game_backups/` 保存每个条目的首次安全恢复点，用于“恢复原版”。
- 所有 JMP 都采用相同流程：索引、边界、路径、解压内容和目标条目校验通过后即可写入，不再按包头名称区分功能。

## 批量编辑

- “全选”选择当前界面的全部节点。
- 每个分组标题右侧的“全选本组”可一次选择该组节点。
- “反选”会切换当前界面的全部选择状态。
- 普通单击只选择当前节点，Ctrl 点击或节点前的复选框可增减选择，Shift 点击可连续选择。
- 多选后修改右侧的坐标、尺寸、缩放、透明度、显示或锁定属性，会统一应用到所有已选节点。

现已同时提供“大厅”和“竞技场对战”两种编辑模式。竞技场模式只针对正常竞技场 HUD，
不包含 PVE、训练、OB、特殊玩法和结算界面。

竞技场使用 1920×1080 设计坐标，并可切换 1280×800、1366×768、1600×900、
1920×1080、2560×1440 预览。每个板块保存左上、顶部居中、右上、两侧居中、
底部等锚点；游戏窗口或全屏分辨率变化时，补丁会在原生分辨率处理完成后重新应用锚点偏移。

这是一个独立项目，不修改也不依赖“300资源工作室”的源码。项目内已经复制了所需的 JMP 读取能力。

## 功能

当前版本支持：

- 扫描游戏目录中的全部 `Data*.jmp`；
- 按 JMP 内部路径跨包定位大厅相关 Lua；
- 建立 1280×800 的大厅场景模型；
- 普通大厅与 Live2D 大厅状态切换；
- 板块树；
- 实时拖动、缩放、显示/隐藏、锁定、透明度和对齐；
- 撤销与重做；
- 保存 `.halllayout.json` 项目；
- 从 `projects` 下拉列表加载上次保存的项目；
- 从外部 `.halllayout.json` 导入项目；
- 导出 `hall_layout.lua`、JSON、manifest 和用于审查的相关 Lua；
- 完整抽取大厅 Lua 直接引用资源与动态资源目录，保留 JMP 内部目录结构；
- 为 BMP、DDS、TGA 生成网页 PNG 预览副本，原始文件同时保留。
- 提供“预览 Lua 差异”“生成补丁”“应用到游戏”和“恢复原版”；
- 应用前保存本次目标文件的上一个版本，写入后逐字节读取校验。

应用到游戏前请先查看 Lua 差异，并关闭游戏和启动器。

## 源码启动

双击：

```text
start_editor.bat
```

或者运行：

```powershell
python app.py --game-dir "D:\JumpGame\300Hero"
```

程序只监听本机 `127.0.0.1`，自动打开浏览器。命令行窗口保持运行，关闭命令行窗口即可停止服务。

## 文件结构

```text
app.py               本地 HTTP 服务和项目保存/导出接口
hall_scene.py        跨包 Lua 定位、统一大厅场景、Lua 配置导出
jmp_core.py          JMP 读取、验证、备份、写入和恢复
arena_scene.py       竞技场场景分析与节点定义
arena_patch.py       竞技场布局补丁生成与应用
lua_patch.py         大厅布局补丁生成与应用
additional_options.py 附加功能补丁管理
resource_export.py   大厅资源抽取与预览转换
settings_store.py    游戏目录配置保存
version_history.py   每次应用前的版本留档
web/                 网页实时编辑器
assets/raw/          从 JMP 抽出的原始大厅资源
assets/web/          浏览器可直接显示的资源副本
assets/manifest.json 完整资源来源、包号、索引和 MD5
projects/            保存的布局项目
exports/             导出的布局目录
game_backups/        应用到游戏前保存的首次原始 JMP 条目快照
version_history/     每次应用前抽取的上一个版本
option_baselines/    附加选项首次启用前的逐文件原始数据
option_templates/    经参考包验证的附加选项 Lua 模板
```
